LADIES & KIDS ZONE - Android App Project
=========================================
এটি একটি অফলাইন দোকান ব্যবস্থাপনা অ্যাপের Android Studio project।

ফিচার:
- Dashboard
- পণ্য/স্টক
- বিক্রি ও Invoice
- Customer ও বাকি
- আয়-ব্যয়
- রিপোর্ট
- LocalStorage ভিত্তিক অফলাইন ডাটা
- ব্যানারের মতো গোলাপি/বেগুনি/নীল থিম
- "শুভ উদ্বোধন" রাখা হয়নি

APK বানাতে Android Studio-তে project folder খুলে Build > Build APK(s) নির্বাচন করুন।
